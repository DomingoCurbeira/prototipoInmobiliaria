# InmoStudio Costa Rica 🇨🇷 🏡

> Prototipo de Portal Inmobiliario de Alta Gama y Plataforma de Marca Blanca para Bienes Raíces en Costa Rica.

---

## 🌟 Características Principales

* **🇨🇷 Mercado Costarricense Bimoneda (USD / CRC):**
  * Conmutador dinámico en la cabecera para alternar entre **Dólares ($ USD)** y **Colones (₡ CRC)**.
  * Visualización simultánea del precio en la moneda principal y su contravalor de referencia en la secundaria (calculado automáticamente con tipo de cambio oficial).
  * Propiedades en ubicaciones emblemáticas: **Escazú (Jaboncillos), Santa Ana (Lindora), Manuel Antonio (Quepos), Rohrmoser (La Sabana), Curridabat (Pinares), Tamarindo (Guanacaste) y Barrio Escalante**.

* **🎨 Marca Blanca & Modo Demo en Tiempo Real:**
  * Personalizador flotante para adaptar la web frente al cliente en 1 segundo:
    * Nombre de la inmobiliaria y eslogan.
    * Canales de contacto directos: teléfono, WhatsApp oficial y **SINPE Móvil**.
    * **4 Paletas de color premium** con persistencia automática en el navegador:
      * 🏛️ *Oro & Pizarra (Luxury Gold)*
      * 🌿 *Esmeralda & Naturaleza (Costa Rica Tropical)*
      * ☀️ *Terracota & Sol del Pacífico*
      * 💎 *Zafiro & Corporativo (Navy)*

* **🔍 Buscador Multifiltro Inteligente:**
  * Pestañas para **Comprar** o **Alquilar**.
  * Filtros por tipo de inmueble (Casa en condominio, Apartamento en torre, Penthouse, Villa de playa, Dúplex).
  * Filtros avanzados por comodidades: piscina, parqueo techado, terraza, ascensor, seguridad 24/7 y solo rebajadas.

* **🏷️ Fichas de Propiedades con Métricas Visuales:**
  * Iconos directos de **Dormitorios, Baños completos, Parqueos/Cochera y Metros cuadrados (`m²`)**.
  * Mini-carrusel de fotos dentro de la propia tarjeta con contador.
  * Insignias de estado: *Exclusiva*, *Rebajado*, *Novedad* y *Reservado*.
  * Botón directo para consultar por WhatsApp con la referencia de la propiedad precargada.

* **📋 Ficha Detallada (Modal Inmersivo):**
  * Galería fotográfica con selector de miniaturas.
  * Checklist de amenidades y cuota condominal (HOA).
  * Tarjeta del asesor asignado con llamada directa y WhatsApp.
  * Estimación de cuota mensual para crédito hipotecario en Costa Rica.

* **🧮 Calculadora de Crédito Hipotecario (Costa Rica):**
  * Ajuste interactivo de valor de propiedad, prima inicial (10%-50%), años de plazo e interés anual.
  * Estimación de cuota y desglose de gastos legales/notariales de traspaso en Costa Rica (~4%).
  * Botón directo para solicitar precalificación bancaria con entidades costarricenses (BAC Credomatic, BN, BCR).

* **🤝 Sección de Captación para Propietarios:**
  * Formulario rápido para solicitar valoración gratuita de mercado por WhatsApp.

* **❤️ Cajón de Favoritos:**
  * Permite guardar viviendas, ver el total acumulado y consultar por todas ellas en un solo mensaje de WhatsApp.

## 🛠️ Tecnologías Utilizadas

* **Framework:** React 19 + TypeScript
* **Herramienta de construcción:** Vite 8
* **Estilos:** Tailwind CSS v4 + Variables CSS dinámicas para temas en tiempo real
* **Iconografía:** Lucide React

---

## 🚀 Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/DomingoCurbeira/prototipoInmobiliaria.git

# 2. Entrar a la carpeta del proyecto
cd prototipoInmobiliaria

# 3. Instalar las dependencias
npm install

# 4. Iniciar el servidor de desarrollo
npm run dev
```

La aplicación estará disponible localmente en `http://localhost:5178/` (o el puerto indicado por Vite).
